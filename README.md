# Бортжурнал E46

Сервисная книжка для BMW E46: расшифровка VIN, регламент ТО под конкретный мотор, журнал замен, слабые места.

Открыть: https://vladvan7.github.io/bmw-e46/ — на телефоне «Поделиться → На экран „Домой“».

Данные хранятся только в памяти браузера на устройстве; резервная копия — в разделе «Журнал».
